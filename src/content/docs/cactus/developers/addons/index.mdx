## What are Addons?

Addons are separate mods that integrate with Cactus through a dedicated API. They follow the standard mod loading process (Fabric/NeoForge) but use Cactus-specific entrypoints and systems to register their content.

## Supported Content Types

Addons can register the following types of content:

- **Modules**: Client-side features that can be enabled/disabled
- **Commands**: Chat commands for various functionality
- **HUD Elements**: Custom display elements on the HUD
- **Content Packs**: Themed content collections
- **Placeholders**: Dynamic text replacements
- **Configuration Files**: Custom settings and data
- **Screenshot Upload Providers**: Custom image upload services
