Cactus Mod is a **client-side mod**: it only changes your own game, so it works on every normal server - no special server setup is needed.

## Requirements

- **Minecraft**: Version `1.20.1` or newer.
- **A mod loader**: Cactus runs on **Fabric**, **NeoForge** and **Quilt**. Fabric additionally requires the **Fabric API** (latest for your MC version).

## Download Sources

Cactus can be downloaded from three places:

- [Releases Page](https://cactusmod.xyz/downloads)
- [Modrinth](https://modrinth.com/mod/cactus)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/cactus-mod)

:::caution

The above listed sources are the **only legitimate** places to download cactus. In the past, we've had to deal with people impersonating us to spread malware. Please only download cactus from these places.

:::

## Installing with Common Launchers

Most launchers have integrations for Modrinth and/or CurseForge, so you can usually install Cactus directly from within the launcher - no manual downloads required.

### Prism Launcher

1. Create a new Fabric (or NeoForge) instance for the latest Minecraft version Cactus is compatible with.
2. Right-click the instance and select **Edit** → **Add Content**.
3. In the **Modrinth** (or CurseForge) tab, search for `cactus mod`, select it and click **Install**.
4. If you are playing on Fabric, also search for and install `fabric api`.
5. Launch the instance.

### Modrinth App

1. Create a new project and pick **Fabric** (or NeoForge) as the loader for your Minecraft version.
2. Use the **Add content** button to search for `cactus mod` and install it.
3. On Fabric, also add the `fabric api` mod the same way.
4. Start the project.

### CurseForge App

1. Create a **Custom Profile** with your Minecraft version and the Fabric or NeoForge loader.
2. In the profile, use **Add More Content** (+ button) → **Mods** to open the search.
3. Search for `cactus mod` and install it.
4. Restart Minecraft.

### ATLauncher

1. Create a Vanilla Minecraft instance and select **Fabric** (or NeoForge) as the mod loader.
2. Open the instance and go to **Mods**.
3. Search for `cactus mod` and install it from Modrinth or CurseForge.
4. On Fabric, also search for and install `fabric api`.
5. Start Minecraft.

### GDLauncher

1. Create a new instance for your Minecraft version and pick **Fabric** (or NeoForge) as the loader.
2. Open the instance's **Mods** section and use the mod search to install `cactus mod` from Modrinth or CurseForge.
3. On Fabric, also search for and install `fabric api`.
4. Launch the instance.

## Manual Installation

If your launcher has no mod-store integration, or you want a specific version from Cactus' website:

1. Download the latest `.jar` file for your Minecraft version (e.g. `cactusmod-0.9.96.jar`) from one of the download sources above.
2. Open your instance folder → `mods` (most launchers have an "Open Folder" or "Open Mods Folder" button).
3. Drop the downloaded JAR file into the `mods` folder.
4. On Fabric, make sure **Fabric API** is in the `mods` folder as well.
5. Start Minecraft.
